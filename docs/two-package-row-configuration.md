# test4: 纵向双套餐配置

这是独立默认记录，不修改蓝色特权模板、test3 或已保存的个人记录。使用现有组件与参数，无专用 CSS 或新增组件类型。

## 层级

商品选择布局容器（纵向，间距 16）
- 商品套餐：年套餐，默认选中
  - 布局容器：横向、两端对齐、居中
    - 左列布局容器：纵向
      - 标题行布局容器：横向，绑定SKU周期名称“12个月”和划线原价
      - 文字：绑定商品信息，当前显示“节省63%”
    - 右列布局容器：纵向、右对齐
      - 文字：绑定配置标签“🔥30% OFF”，橙色胶囊背景
      - 文字：绑定月均价
- 商品套餐：月套餐
  - 布局容器：横向、两端对齐、居中
    - 文字：绑定SKU周期名称“1个月”
    - 文字：绑定月均价

## 参数

| 所属组件 | 配置 |
|---|---|
| 外层布局容器 | 宽度填满，高度适应内容，纵向，间距 16，左右外边距 16 |
| 两个商品套餐 | 宽度填满，固定高度 72，圆角 16，内边距上下 8 / 左右 10 |
| 商品套餐未选中 | 背景 #f0f0f0，边框透明 |
| 商品套餐选中 | 背景 #ffede9，边框 #ff8a00 / 1px |
| 套餐内容布局容器 | 横向、两端对齐，宽高填满；左右两列宽度适应内容 |
| 年套餐 SKU | DEMO-SKU-YEAR：总价 ¥338，月均 ¥28.17/月，参考价 ¥488 |
| 月套餐 SKU | DEMO-BLUE-MONTH：¥78/月 |
| 参考价文字 | 绑定参考价，启用删除线，灰色 |
| 月均价文字 | 绑定月均价，右对齐 |
| 角标文字 | 橙色背景、白字、圆角 20，宽度适应内容 |

周期、价格、商品信息、标签均通过所属Package绑定。标签原文保存在示例商品配置中，不计算折扣倍率；年价¥338与最短周期月价¥78比较后向下取整，显示“节省63%”，不再固定写64%。套餐内文字在默认规则显示“内容来源：自定义文字 / 商品字段”；切换为自定义时保留当前文案，后续不再跟随SKU。

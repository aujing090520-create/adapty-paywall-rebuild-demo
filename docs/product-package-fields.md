# 商品套餐前端字段定义

来源：[运营《现有paywall组件拆解》](https://hellotalk.feishu.cn/wiki/OZaiwRnxNimqYtk5meDcIlRonOc)，读取版本17及4张配图；补充口径以2026-10-27用户确认优先。本文件对应Demo实现，不修改原飞书文档。

## 元素对应

| 前端元素 | 绑定字段 | 来源及显示规则 |
|---|---|---|
| 商品标签 | badgeText / selectedBadgeText | 读取其他地方配置的原文，选中与未选中分别读取。没有配置时：年套餐“最受欢迎”、终身“物有所值”、月及其他周期为空。不会由价格或节省比例生成7折、30% OFF等文案。 |
| 周期名称 | name | 绑定SKU名称。组件只调字体、颜色、布局，不修改SKU名称。 |
| 售卖价 | price | 绑定SKU售价，展示总价或月均价。 |
| 划线价 | reference | 绑定真实原价；先在相同周期比较原价与售价，原价缺失、等于或低于售价时不展示，不拿当前售价的换算结果充当原价。 |
| SKU原价总价 | referencePrice | 原价字段直接绑定，同样执行有效性检查。 |
| SKU月均价 | monthlyPrice | 当前SKU的月均售价，与节省比例计算分开；展示金额的舍入不参与节省比例计算。 |
| 商品信息：节省比例 | productInfo | 同一选择组、同一场景、同币种的可见套餐中，以最短订阅周期作为基准。将目标售价归一化到基准周期后比较，百分比向下取整。 |
| 商品信息：终身权益 | productInfo | 终身商品显示“永久会员权益”，不参与订阅周期换算。一次性点数商品不视作终身会员。 |
| 选中框/背景 | Package状态样式 | 只控制样式与选中态，不拥有价格、周期或标签文案。 |

商品套餐仍拥有SKU绑定、选择组和默认选中。内部布局容器仅排列标签、周期、价格和信息，所有文字/容器仍可单独调整视觉样式。

## 计算口径

- 固定换算：1年＝12个月＝52周；1个月＝52÷12周。
- 节省比例＝floor((1－目标套餐售价÷目标周期长度×基准周期长度÷基准套餐售价)×100)。使用未舍入的价格与整数周期比例计算，不使用已经保留两位小数的月均价二次计算。
- 年价¥488、月价¥78：计算结果47.86…%，显示“节省47%”。
- 年价¥260、周价¥10：显示“节省50%”。月价¥26、周价¥10：显示“节省40%”。
- 最短周期自身、没有比较基准、基准为0、未知周期、币种不同、同一最短周期存在冲突售价，均不猜测基准；不展示节省比例。相同基准SKU重复出现不构成冲突。
- 没有正向节省时不展示优惠宣称。隐藏套餐、其他页面/弹窗/标签状态及其他选择组不参与当前组比较。

## 配置与兼容

- 新商品套餐组件默认具备标签、周期、划线价、售价、商品信息五种可视子元素。绑定SKU后，属性面板展示只读来源值。
- 现有savingCopy/saveCopy绑定兼容到派生信息，不再读取固定的“节省48%”示例。其他普通文字仍是独立的设计内容，不按文字内容批量改写。
- 四张HT模板新建/重新应用时补齐可视字段。已有保存画布不强制增加、移动或删除节点；已有业务绑定读取新的计算规则。
- 创建页旧商品表保持删除，不恢复offerRows等联动；标签源在Demo商品数据中模拟，未宣称接通真实Paywall管理、运营多语言词条或计费服务。
- 本地金额样本使用¥/$及显式币种；不将此Demo解析器宣称为已接通所有国家/商店的本地化价格接口。

# 统一退出挽留创建流程

## 范围与来源

- 用户选择统一“空白／模板／已有内容”入口，并追加截图明确：权益行只是链接，不应显示步骤流；挽留必须能按录屏创建流程、选择页面并创建，同时看得出关闭来源。
- 延续已核对的20261025154034录屏创建逻辑，复用现有StepPicker，不新造第二套选择器或第二份触发字段。
- 保留原HT源模板、正文、素材和SKU；普通步骤、详情链接、普通Sheet及独立退出优惠不合并语义。真实Billing及系统关闭仍排除。

## 本次路径

1. 画布“创建流程” → “关闭后挽留” → 空白弹窗 / 模板 / 已有内容 → 选屏幕或弹窗 → “创建退出优惠”。创建前显示关闭哪个最终页面。
2. 普通弹层画板“配置触发”或弹层上下文“配置退出触发”，打开相同流程并预选当前弹层；确认前不转换、不绑定。
3. 付费墙设置“新建退出优惠”进入同一选择器；“使用当前弹层”也先进入确认，不再选择即修改。
4. 模板/已保存内容复制为独立优惠；当前弹层确认后转换；不增加查看详情按钮。普通下一步骤仍可使用原空白/模板/已保存来源。
5. 联合编辑时，即使选中优惠，交互预览也先从主流程开始；关闭最终页面才展示优惠，取消后结束整个流程。普通Sheet的上下文预览保留。

## 复制与状态

- 取消或仅选择来源不改变文档/绑定；创建后仍为工作会话，顶部保存才联合写入，放弃恢复旧内容。
- 空白弹窗无预填文字、无商品继承；没有商品时明确不可触发，不画虚假有效连接。
- 模板弹窗保留原图、文案、几何及购买/取消适配。屏幕来源保留实际链接依赖，内部目标、节点、商品记录重新生成ID，字体资源随引用复制；默认选中商品保持，不改源记录。
- URL/OpenPage详情不画步骤边；仅真实NextScreen与退出关闭事件参与步骤流。辅助详情不默认占主流程画板，仍可从真实图层选中编辑，链接动作不改写。

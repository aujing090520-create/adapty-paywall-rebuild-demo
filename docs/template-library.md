# 模板库

## 三个来源

- 官方模板：代码内置模板，只能套用，不能在模板库覆盖、删除或共享。
- 自定义模板：构建器顶部“保存为模板”，输入名称后保存当前完整配置快照；包括多页面、组件样式、参数、图片引用、字体和按钮下弹窗。保存不等于创建或保存付费墙记录。
- 共享模板：自定义模板点击“共享”、确认公开后实际上传云端。所有访问者无需账号即可读取和套用，不再是本地模拟。旧版模拟共享记录不自动上传。

自定义和共享模板套用时深复制配置；编辑副本不会修改源模板、已创建付费墙或官方默认值。再次保存为模板创建一份新快照，不隐式覆盖原模板。

自定义模板支持重命名、共享/取消共享及移入回收站。回收站提供恢复，没有永久删除入口；移入回收站会自动取消共享，恢复不会自动再次共享。已套用的付费墙不依赖模板记录继续存在。

## 无账号管理边界

自定义模板仅存在当前浏览器当前域名；共享后配置快照进入原Vercel项目关联的私有Blob存储，通过 `/api/shared-templates` 公开读取。上传者浏览器保存每份模板的随机管理凭证，服务端仅存其哈希。其他访客不能改名或撤回。没有账号登录，也不将浏览器等同于真实个人身份。

本地存储键：`paywall-user-template-library-v1`（模板）和 `paywall-share-capabilities-v1`（管理凭证）。管理凭证不进入模板配置、URL、公共接口响应或Git。清除浏览器站点数据会失去管理权；换设备或换域名不会自动继承。Demo“重置本地设定”清除本地模板库，但特意保留共享管理凭证，便于重新打开共享列表后撤回。

共享须明确确认，提醒不要公开个人资料、内部接口密钥或敏感内容。撤回后列表和读取接口立即停止提供该模板，已经被套用的副本不受影响。网络失败时不清除本地配置或上传重试标识；移入回收站前必须先成功撤回。恢复本地记录不会再次自动共享。

活动中的旧外部挽留弹窗，在保存快照前使用现有迁移器复制为按钮下弹窗；关联目标缺失时拒绝保存并提示修复，不保存断开的流程。已失效的旧关联历史不继续写入新快照。

## 接口与容量

- `GET`：公开列表；`GET ?id=...`：公开配置，不返回管理哈希或来源IP信息。
- `POST`：上传配置快照；`PUT ?id=...`：改名；`DELETE ?id=...`：撤回，不物理删除私有文件。写操作使用每份模板独立的Bearer管理凭证。
- 私有存储令牌只通过服务端环境变量注入；生产和开发环境共用此库，预览部署未绑定。普通静态文件服务器没有API，不能假装共享成功。
- 条件写入防并发覆盖；目录读取禁用缓存并使用未压缩源ETag，避免压缩弱校验值导致写入冲突。相同标识和配置的失败重试不会生成重复模板。
- 单份最大2MB、1800个组件，仅支持标准组件，拒绝自定义可执行代码和浏览器临时资源。嵌入图片计入体积，远程资源需能被其他访客访问。
- 最多50份有效/待完成共享、累计250份标识；每天20次新上传、100次管理写操作；同一来源每小时5次新上传，读取另有实例级频率限制。来源IP仅加盐哈希用于限流。

这是小规模匿名演示库，不提供生产级抗恶意流量保障。达到平台或应用额度会报错，不自动升级付费计划。没有账户恢复、真实身份认证或跨设备私有同步。

## 验证

- 保留本地快照、三TAB、回收站、名称、损坏存储及旧弹窗依赖回归；新增匿名读取、越权拒绝、持久限流、并发重试、撤回、结构/体积检查及旧模拟记录隔离测试。
- 真实私有存储验证上传、读取、条件改名和撤回。两个独立站点验证上传者共享、访客读取并套用完整配置，访客没有改名/撤回入口。
- 验收记录完成后从共享库撤回，未改用户原付费墙记录。

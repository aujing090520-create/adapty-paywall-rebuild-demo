# 模板库

## 三个来源

- 官方模板：代码内置模板，只能套用，不能在模板库覆盖、删除或共享。
- 自定义模板：构建器顶部“保存为模板”，输入名称后保存当前完整配置快照；包括多页面、组件样式、参数、图片引用、字体和按钮下弹窗。保存不等于创建或保存付费墙记录。
- 共享模板：自定义模板点击共享后，同时出现在此 TAB。取消共享后只从共享列表移除，自定义模板仍保留。

自定义和共享模板套用时深复制配置；编辑副本不会修改源模板、已创建付费墙或官方默认值。再次保存为模板创建一份新快照，不隐式覆盖原模板。

自定义模板支持重命名、共享/取消共享及移入回收站。回收站提供恢复，没有永久删除入口；移入回收站会自动取消共享，恢复不会自动再次共享。已套用的付费墙不依赖模板记录继续存在。

## 本地演示边界

按本轮用户确认，模板仅使用当前浏览器当前站点的本地存储。没有账号鉴权和云端模板 API；共享是本地状态模拟，不会让其他浏览器或其他人实际看到。界面持续展示此边界，不将当前浏览器等同于真实个人账号。不同域名的本地数据不互通。

存储键：`paywall-user-template-library-v1`。读写失败保留编辑状态并显示错误；损坏库不静默覆盖。Demo“重置本地设定”包含模板库；其他应用存储不动。没有向云端上传配置、资源或凭据。

活动中的旧外部挽留弹窗，在保存快照前使用现有迁移器复制为按钮下弹窗；关联目标缺失时拒绝保存并提示修复，不保存断开的流程。已失效的旧关联历史不继续写入新快照。

真实多人版仍需：登录账号、服务端 owner 权限、共享发布与撤回、文件存储与版本管理。本轮未实现这些接口，也不模拟账号切换来冒充鉴权。

## 验证

- 968 项完整测试通过，覆盖配置快照深复制、三 TAB、共享撤回、回收站恢复、名称校验、损坏存储与空间不足保护、旧弹窗依赖及存储重置。
- 独立本地浏览器实际走通：官方模板改页面名称、另存自定义、共享列表、套用副本、修改副本不回写、取消共享、重命名、回收站恢复、重新打开后保留以及官方默认名称不变。
- 验证数据仅在隔离的本地测试站点；未改用户原付费墙记录。

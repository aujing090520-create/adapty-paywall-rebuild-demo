# 组件对照验收：结构、配置归属与使用闭环

## 来源与范围

- 当前依据：[RevenueCat组件](https://www.revenuecat.com/docs/tools/paywalls/creating-paywalls/components)、[通用属性](https://www.revenuecat.com/docs/tools/paywalls/creating-paywalls/component-properties)，以及用户已提供的图层截图和倒计时录像。官方文档在2026-10-29重新读取；旧原站审计只能作为历史证据，不冒充本轮原站逐字段操作。
- 本轮对33类内部组件逐个打开实际Properties与Preview，核查父子边界、可见字段和输出；针对发现的问题操作控件、读回渲染、增加保存/复制回归。[浏览器面板遍历记录](evidence/reference-audit-20261029/component-panel-results.json)、[实际徽标渲染](evidence/reference-audit-20261029/button-badge-sized.jpg)。
- 不修改原参考站草稿、模板素材、用户记录、SKU数据、价格/标签定义；不接真实支付，不修改代理。已有test-results/不提交。
- 源码中有字段不等于用户能找到入口，渲染通过不等于完整还原。下面分别记录已修复、已确认正确、主动差异和外部边界。

## 问题台账

| ID | 分类 | 证据和处理 | 验证 | 状态 |
|---|---|---|---|---|
| RA01 | 实际使用缺陷 | Carousel的过渡时间/动画被错误放在autoPlay条件里；手动切换本来也消费这两个字段。移动至独立配置，只有每页停留时间依赖自动切换 | 浏览器autoPlay=false时设650ms/fade，点击第二页确实切页；回归断言不改自动播放 | 已修改 |
| RA02 | 参考语义差异 | Timeline连接线从图标边缘起算，参考定义从中心起算。改为中心到中心，再扣上下留白，保留缩放换算 | 实际画布缩放0.6333时上下留白均为10设计像素；几何回归覆盖0.5缩放 | 已修改 |
| RA03 | 无效配置 | 标记图标隐藏后仍被视为有效连接对象，导致连接线设置继续显示。渲染和面板都按可见标记判断 | 隐藏后设置消失，重新显示恢复原7px值；删除标记同样处理 | 已修改 |
| RA04 | 配置入口遗漏 | 原来只有Stack/Package/Slide/PurchaseButton能配置徽标；其余普通父容器已有实际徽标渲染。补齐Button/Header/Footer/BottomSheet/Tab/TabControl/TabButton/PageControl/CheckoutState/SwitchCase/CountdownState入口，不添加虚构子图层 | 15种支持类型逐项回归；新增11种实际浏览器启用、编辑为“限时福利”、关闭后消失，正文不变 | 已修改 |
| RA05 | 复制闭环缺口 | copyStyles遗漏父组件徽标。复制徽标外框、整体字体、位置和启用状态；保留目标徽标正文/选区格式、子组件正文、动作和商品数据 | 真实操作函数复制/粘贴及保存读回；目标文案和runs不被源文案覆盖 | 已修改 |
| RA06 | 验收盲区 | 验收台没接父Countdown编辑/定位和Package分组回调，目录遍历可能遗漏实际入口。接入生产相同操作函数 | 33类浏览器面板遍历，无错误；Countdown父级可见实际文字编辑器 | 已修改 |
| RA07 | 排除误报 | Video在textPropertyPatch中已有无播放入口保护，不是看到面板字段就能断言组合失效 | 原有互斥回归通过；不重复实现 | 确认不修改：已有正确保护 |
| RA08 | 排除误报 | 原生Toggle在ContentSection前部已有提前返回，只提供颜色；尾部普通控件不是它的真实入口 | 浏览器只显示滑块/轨道4个颜色字段，修改滑块为rgb(238,51,68)生效 | 确认不修改：原生与旧协议已有分界 |

RA04只覆盖本轮已证明能渲染徽标的普通容器；不据此宣称Screen、Carousel、Timeline等特殊父组件也已具有完整徽标能力。

本批统计：6项已修改（其中5项产品问题、1项验收工具），2项确认不修改（排除误报）。740项测试通过，构建通过；生成参数参考为33类、4734条定义。发布与生产路径结果见同批交付回执，不用本地结果替代生产验收。

## 逐组件覆盖

下表表示本轮核查边界，不表示穷举每个字段组合或与原生SDK逐像素等价。

| 内部组件 | 结构及配置归属 | 本轮结论/限制 |
|---|---|---|
| Screen | 场景根，拥有直属Header/Footer和滚动正文 | 固定区不属于普通Stack；不是原子目录中的独立页面组件 |
| Stack | 横/纵/叠放布局，直接拥有子项 | 排序、礼包/福利列表属于已确认Demo扩展，非参考原生能力 |
| Text | 正文、格式、变量在同一编辑器 | 多变量混排；未知变量保留并提示，不执行表达式 |
| ProductParameter | 商品字段映射，样式可编辑、数据非自由文案 | 用户明确要求的Demo参数组件，不是RevenueCat同名原子组件 |
| Image | 叶子媒体，适配/遮罩/叠加归图片 | PAG为Demo扩展；无业务PAG样例，不声称真实业务播放已验 |
| Video | 叶子视频，播放参数归视频 | 保留已有自动播放/播放控件组合保护；浏览器自动播放政策仍适用 |
| Icon | 固定宽高，图案/颜色/背景归图标 | 不承载按钮动作；关闭/返回由Button→Icon组成 |
| Custom | 隔离ZIP网页，旧HTML兼容 | 购买仍由原生Package/PurchaseButton承担，真实CDN/原生WebView未模拟等价 |
| Header | Screen直属且唯一的固定顶部区 | 不把普通导航行Stack强制转换为Header |
| Footer | Screen直属且唯一的固定底部区 | 蓝色特权商品保持正文区，倒计时/按钮/协议按已确认布局 |
| Package | 选择组、默认/选中、商品类型与价格模式归套餐 | SKU引用占位与业务参数组件为已确认主动差异，不回退真实价格 |
| PurchaseButton | 独立购买动作容器，真实文字/图标子层 | 真实支付排除；切换导航动作后保留既有类型转换 |
| BottomSheet | 归触发Button拥有，内容在弹窗内 | 每屏可独立绑定是Demo扩展，不回退全局图层触发 |
| ExpressCheckout | 三个互斥CheckoutState | 设备钱包可用性为演示状态，非真实钱包能力检测 |
| CheckoutState | 快捷结账所属的可用/不可用/加载内容 | 不作为普通内容目录自由添加；本轮补徽标入口 |
| Wallet | 所属可用结账状态中的原生控件 | 样式可配，购买校验共用；不发真实交易 |
| Button | 动作/步骤/链接/弹窗绑定归按钮 | 子图标/文字不重复拥有导航路径；补徽标入口 |
| Tabs | 多Tab及默认Tab归父级 | 每个Tab拥有独立内容，选择器样式按既有规则同步 |
| Tab | 所属Tabs的一屏内容 | 不等同流程Screen；补徽标入口 |
| TabControl | 标签按钮组，目标绑定所属Tabs | 不是普通通用布局Stack；补徽标入口 |
| TabButton | 目标Tab与默认/当前样式 | 文案在实际Text中；补徽标入口 |
| Carousel | Slide序列、默认页、循环/自动/过渡归父级 | 修复手动切换的过渡配置入口；实际切换使用既有Embla |
| Slide | 单独可编辑轮播页面内容 | PageControl不计入页面数量 |
| PageControl | Carousel直属唯一分页控件 | 位置归轮播，间距归分页控件；补徽标入口 |
| Indicators | PageControl直属指示器样式 | 默认/当前独立，实际按页重复，不生成假页 |
| Timeline | 图标对齐、三种间距归父级 | 修正中心连接几何；不把时间线降为一块文字 |
| TimelineItem | 实际图标/标题/可选说明和连接线 | 隐藏/无标记/末项不暴露无效连接设置 |
| Switch | ON/OFF内容与默认状态归父级 | 不降为协议勾选框；真实平台原生外观未声称一致 |
| SwitchCase | Switch所属状态内容 | 可配置实际内容，不复用另一状态正文；补徽标入口 |
| Toggle | Switch内控件或旧HT协议控件 | 原生分支只配颜色；协议分支保留required等已有规则 |
| Countdown | 时间来源、单位、状态内容归父级 | 单条变量文字已保留；业务时间源和数据不可用兜底为主动扩展 |
| CountdownState | 计时中/已结束/可选兜底的内容 | 不把状态当固定常驻内容；补徽标入口 |
| Flow | 同级Screen、初始步骤和按钮连接 | 不以画板左右位置推导导航；按钮实际目标不变 |

## 未冒充完成的边界

- 本轮当前外部对照是官方定义与用户提供证据；没有重新声称在登录原站逐字段修改了全部组件。
- 缺少业务PAG文件、真实Offering/支付、宿主原生导航栏、SDK不支持降级环境。这些不以Web演示通过替代。
- 新版参考站的延迟关闭/系统导航栏等涉及支付退出路径或平台宿主行为，本轮不自动引入；保留现有即时关闭规则。
- 徽标选区格式在样式粘贴时保留目标值，不按源字符串长度强行覆盖；非承诺任意富文本选区样式映射。
- 87份模板结构/渲染回归与33类面板遍历是两类证据，不等于87份模板逐像素对齐。

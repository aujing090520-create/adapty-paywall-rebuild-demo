# 挽留弹窗配置路径修复

## 一条配置路径

1. 已有挽留弹窗：在左侧选中“挽留弹窗”，点击预览上方“转为退出优惠”；也可在“付费墙设置 → 退出优惠 Offering”选择“使用当前弹层 · 挽留弹窗”。
2. 进入独立退出优惠编辑区，直接修改现有文字、图片、倒计时和按钮；“返回主付费墙”回到主页面。左侧“退出优惠”始终提供再次编辑入口。
3. 点击工作台顶部“保存”，一起保存主付费墙绑定和当前退出优惠文档。转换和编辑本身不自动保存；“放弃修改”、重新套用模板或未保存离开，都不把临时优惠草稿写成模板默认。
4. 其他模板可在付费墙设置“新建退出优惠”，直接得到独立弹层编辑区，不向主页面添加“查看详情”按钮。没有商品时需先添加商品才能演示退出优惠。

## 模型边界

- [RevenueCat按钮Sheet](https://www.revenuecat.com/docs/tools/paywalls/creating-paywalls/components#navigate-to-sheet)和[独立Offering退出优惠](https://www.revenuecat.com/docs/tools/paywalls/creating-paywalls#configuring-exit-offers)继续区分。“转为退出优惠”是本Demo迁移旧HT结构的命令，不是虚构的RevenueCat组件属性。
- 普通目录入口改名“按钮弹层”，继续保留按钮打开Sheet能力。转换只清除指向该弹层的生成按钮，其余嵌套弹层保留；自定义关闭控件转为退出动作，不随意删除其内容。
- 独立优惠复制现有弹窗的素材、正文、几何与商品数据；渲染保留原主页面的只读背景，取消结束整体会话。旧“领取按钮”接购买演示，旧取消文案成为可点击关闭控件，不发起真实交易。
- Offering商品数量来自商品数据，而不是画面中的Package选择框数量；挽留优惠可以没有可见的商品选择框。四张HT模板源定义不改。

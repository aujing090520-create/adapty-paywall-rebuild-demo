# 倒计时优惠联动

## 配置入口

1. 在图层或画布选中“倒计时”。
2. 在右侧“优惠联动”标题旁点击“添加配置”。
3. 选择“影响套餐”：当前范围全部套餐，或某个套餐选择组。
4. 设置恢复正常价格时是否隐藏商品标签、划线价、节省比例。
5. 在“优惠状态预览”中切换计时中、已结束、数据不可用；选“实时”恢复真实计时。

该能力默认关闭，不自动改变任何模板或已有记录。移除配置只关闭联动，保留套餐的字段、价格显示模式、选中样式和联动配置，重新开启可恢复。

## 运行规则

| 状态 | 展示与购买预览所用方案 |
| --- | --- |
| 计时中 | 优惠价格 |
| 已结束 | 正常价格；仍可正常购买预览 |
| 数据不可用、无效时间、时间源缺失 | 正常价格，不自动重启优惠 |
| 同一套餐绑定多个启用的优惠倒计时 | 正常价格，配置区提示冲突 |

倒计时位于页面或页脚时，作用于当前页面范围；位于轮播页、标签页或状态分支时，仅作用于所在分支。不会跨到另一屏或弹窗。打开详情弹窗不会重启背景页的倒计时。

时间来源继续使用原有配置：
- 统一截止时间：始终指向该 UTC 时间。
- 首次进入后计时：本地演示持久保存截止时间，刷新、再次打开或到期均不重置。
- 每次进入重新计时：离开并再次进入才重置，普通重渲染不重置。
- 业务时间源：引用活动、当前用户优惠或全局时间源，接受结束、不可用及恢复状态；不在组件内重复填写接口地址。

“优惠状态预览”只影响编辑会话，不保存为实际活动状态；交互预览按时间来源运行。购买点击会重新核验时间，不沿用上一帧的优惠判断。

## 字段映射

模板依旧只定义展示字段，不绑定 SKU 或手填价格。

| 原套餐字段 | 计时中 | 正常价格 |
| --- | --- | --- |
| 总价 | `¥{优惠总价}` | `¥{总价}` |
| 月价 | `¥{优惠月价}/月` | `¥{月价}/月` |
| 商品信息 | `{优惠商品信息}` | `{商品信息}` |
| 商品标签 | 原标签 / 选中标签字段 | 默认隐藏，可取消 |
| 划线价、节省比例 | 原字段与样式 | 默认隐藏，可取消 |

终身商品继续遵循现有规则：月价映射总价，划线月价映射划线总价，节省比例不展示。普通自定义文案不会被改写。文字内的 `product.price`、`product.price_per_month`、`product.label` 等变量与商品参数使用同一价格方案。

任意其他组件若需要按状态隐藏、显示或修改文案，可在工作区条件规则中使用“倒计时状态”条件，并选择对应倒计时；无需为活动新造组件。

## 购买与接口边界

本项目只实现配置、展示及购买模拟，不接真实支付或真实业务报价接口。启用联动后，购买、网页结账及自定义结账均只执行购买预览，状态栏明确显示“未发起真实交易”。

`ComponentPreview` 可通过 `onPurchasePreview(payload)` 提供同一份核验结果：

```json
{
  "packageId": "套餐组件ID",
  "priceSource": "discount",
  "countdownId": "倒计时组件ID",
  "state": "active",
  "expiresAt": "2030-01-01T00:00:05.000Z",
  "checkout": "Purchase",
  "simulated": true
}
```

`priceSource` 为 `discount` 或 `regular`。正式接入时，业务服务必须按用户、套餐及活动重新校验有效期并返回权威报价；客户端状态与本地首次进入时间不构成优惠资格或付款金额依据。模板不能自行修改金额，也不能凭本地回调发起真实扣款。

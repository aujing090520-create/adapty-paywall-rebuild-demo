# 倒计时商品联动

## 唯一配置

选中倒计时，在右侧“商品联动”打开或关闭“联动商品”。

| 开关 | 行为 |
| --- | --- |
| 关闭（默认） | 只展示倒计时。即使到期，商品上下文仍保持计时中，不因这个倒计时切换商品。 |
| 开启 | 将计时中、已结束、数据不可用状态交给已有商品逻辑，展示它决定的对应商品。 |

倒计时只负责计时与是否联动，不负责定价或商品选择规则。因此移除上版的影响套餐、价格来源、隐藏商品标签、隐藏划线价、隐藏节省比例及重复的优惠状态预览。原有“显示内容”仍可预览倒计时自身的状态。

商品总价、月价、标签、划线价、节省比例继续由商品参数和商品逻辑提供；模板保留 `¥{总价}`、`¥{月价}/月` 等字段占位，不再改成另造的“优惠总价/优惠月价”。订阅/终身适配、价格模式及默认/选中样式不变。

## 兼容与范围

- 保存一个布尔值 `Countdown.props.linkProducts`。旧版 `promotion.enabled` 仅用于兼容开关状态，旧范围和隐藏字段不再生效；首次切换新开关时清除旧配置。
- 自动归属到当前页面、弹窗或所在分页。不会跨到另一屏；同一范围多个倒计时分别输出上下文，不由前端臆定价格冲突或回退规则。
- 手动统一截止时间、首次进入后计时、每次进入重新计时及业务时间源均保留。
- 开启商品联动不会自动新增、隐藏或删除商品图层。

## 接入边界

本 Demo 未接真实商品服务或支付；不声明已有线上接口已完成接入。

`ComponentPreview.onProductLinkChange(events)` 在交互预览状态改变时输出计时上下文；编辑状态不会调用。事件字段为：

```json
{
  "countdownId": "倒计时组件ID",
  "linked": true,
  "state": "ended",
  "expiresAt": "2030-01-01T00:00:05.000Z",
  "packageIds": ["当前范围内的套餐组件ID"]
}
```

开启时 `state` 为 `active / ended / unavailable`；关闭时恒为 `active`，`expiresAt` 为 `null`，不让纯展示倒计时改变商品上下文。回调只在上下文变化时通知，不每秒重复调用。现有商品层处理这些状态并通过原商品数据入口提供对应商品；模板不增加接口地址或第二套映射配置。

购买模拟点击时再次核验当前时间，并在 `onPurchasePreview` 中提供 `packageId`、`linkProducts`、`countdowns`、`checkout` 和 `simulated: true`。不再返回由倒计时自行判定的优惠价/原价方案。实际商品选择、金额与支付资格必须由已有商品服务核验。

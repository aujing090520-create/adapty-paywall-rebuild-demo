# 聊天中送礼

## 配置边界

- 模板名称及创建样式类型：聊天中送礼。
- 只有礼物面板的会员 TAB 内属于可编辑付费墙。聊天、输入栏、礼物面板顶部和系统指示条是只读宿主预览，不进入组件图层树，不执行聊天动作。
- 页面根容器的“页面展示 → 展示方式 → 嵌入区域”是通用能力，不依赖模板名称或 VIP/PLUS 文案。
- 默认设计尺寸 390 × 314，位置左距 0、顶距 530。在 375 × 812 设备显示约 375 × 302；位置及大小可调整，自动限制在设备视口内。
- 宿主预览可切换为“无背景”，用于其他嵌入场景。生产宿主负责提供实际区域，Demo 不连接真实聊天赠礼接口。

## 组件组合

- 两个普通 Screen，由 Flow 的并列切页模式连接；每个页面有自己的 TabControl/TabButton、三个 Package 和固定 Footer/PurchaseButton。
- VIP 与 PLUS 是模板中可编辑的页面/文字默认值，不是组件内置枚举。
- 套餐均使用现有 ProductParameter，预览展示字段名，不新建价格输入或 SKU 绑定。
- 每个套餐包含商品标签、SKU 时长、划线价、主售价和商品信息，价格显示沿用蓝色特权页的四种组合。主售价与划线价有独立职责，切换模式不会覆盖商品信息或其他套餐；终身商品继续按现有规则将月价映射为总价。
- 旧套餐只有售价而没有划线价时，明确选择“总价 / 月均划线价”或“月均价 / 总划线价”会在售价旁补建一个标准划线价参数；不会重复创建，不影响其他套餐或原节点样式。普通总价/月均价选择不会自动增加划线价。
- VIP 默认选择终身套餐，PLUS 默认选择中间套餐；切换页面保留各页的选择状态。立即支付跟随当前页选中套餐，仅模拟购买。

## 通用按钮提示

- 任意普通按钮选择“点击动作 → 显示文本提示”，填写“提示文案”即可。
- 保留原按钮图标、文字、样式；不新建弹窗节点，不产生页面连线，不导航或发起购买。
- 提示锚定按钮，可读取现有文本变量，内容为纯文本；空内容给出缺少文案反馈，不显示空气泡。
- 再次点击、外部点击、滚动或 Escape 关闭。嵌入场景内的气泡受嵌入区域限制，靠近底部时向上展示。
- 编辑模式仅选中组件。复制、跨屏粘贴及序列化保留动作和文案配置。

# 组件配置与预览映射验收

检查日期：2026-10-24。对象是当前组件文档编辑器，不是旧版模板配置黑盒。四张 HT 模板的文案、素材、SKU、节点顺序和人工配置仍是保护边界。

后续逐组件对标结果以 [RevenueCat 原端逐项核对记录](revenuecat-live-audit-2026-10-24.md) 为准。**下文是历史内部映射基线，不是当前功能清单或连接状态。** 现场读取已恢复并已执行部分真实浏览器参数检查；后续新本地标签的控制绑定超时，新增改动最终浏览器验收及ZIP实测仍未完成。原图标填满职责由真实 Stack 承担，原图标 ID/文案/素材/SKU 保留。

## 证据等级

- 已执行：React 真实组件挂载、配置控件事件、预览输出与分支、保存回读、编辑器重新打开。测试不是手写样式公式的替代实现。
- 已执行：45 张模板结构与来源数据回归、四张 HT 模板保护回归。
- 尚未完成：真实浏览器布局、滚动、像素对比、字体与视频解码、文件选择器操作、外部窗口打开效果、生产页面点击回归。当前浏览器 URL 访问被安全策略拒绝，没有改用其他工具绕过。
- 不在本轮范围：真实 Billing/SKU 交易、真实关闭付费墙、恢复购买、网页结账、兑换优惠码和钱包支付；相关动作只是明确的预览提示，不宣称已接通 SDK。

## 共用字段映射

| 配置 | 存储字段 | 预览作用与规则 | 证据 |
| --- | --- | --- | --- |
| 宽度 | widthMode、width、minWidth、maxWidth | 适应内容/填满/固定；上限下限仅在填满时生效；填满扣除外边距，水平布局平分可用空间 | 30 类节点事件测试；实际排版待浏览器验收 |
| 高度 | heightMode、height、minHeight、maxHeight | 内容高度/百分比填满/固定像素；0 上限为不限制；页面固定高度不再被 844 最小高度强制覆盖 | 30 类节点及页脚页面测试；百分比高度依赖父容器可用高度 |
| 内外边距 | padding*、margin*、*Mode | 轴向与四边模式双向同步；允许负外边距；0 不回退到历史值 | 30 类节点，模式切换、负值、保存回读 |
| 形状、圆角 | shape、radius | 矩形/胶囊/圆形；圆角仅在矩形显示；媒体裁切沿用形状 | 30 类节点与媒体测试 |
| 透明度 | opacity | 0–100 映射为 0–1 | 30 类节点测试 |
| 边框 | borderWidth、borderColor | 可添加/关闭，关闭后不由选中态旧值补回 | 30 类节点与商品选中态测试 |
| 阴影 | shadowX、shadowY、shadowBlur、shadowColor | 启用后编辑偏移、模糊与颜色；关闭清除阴影 | 30 类节点测试 |
| 填充 | fillType、background、backgroundImage、backgroundVideo、backgroundFit | 颜色/图片/视频互斥显示；保留非当前类型素材但不渲染；视频只向容器开放 | 填充类型切换与单视频节点测试 |
| 数字输入 | 对应数值字段 | 允许输入过程暂为空；合法值即时生效，失焦归一非法值；最小值不能大于非零最大值 | 数字草稿与矛盾边界测试 |
| 颜色输入 | 对应颜色字段 | 浏览器原生 CSS 校验；无效草稿标错且不写入配置，失焦恢复上次有效值 | 校验回调与草稿测试；CSS 引擎实际支持范围待浏览器验收 |

## 专属字段与交互

| 组件类型 | 配置内容 | 预览映射 / 限制 |
| --- | --- | --- |
| 文字 | 内容、富文本片段、字体、字号、颜色、粗斜体、下划线、删除线、对齐 | 全局样式同步已有片段；片段文字与总内容一致；绑定 SKU 时内容只读；转为独立文字保留当前值 |
| 图片 / 视频 | 地址、上传、删除、适配；图片遮罩与叠加层 | 更新实际 img/video；上传支持 PNG/JPG/WebP/GIF/MP4，最大 10 MB；背景视频仅允许 MP4；不允许脚本 URL |
| 图标 | 类型、数字、颜色、透明度、背景 | 选择项与真实图标表对应；固定宽高映射 SVG，不再出现第二套冲突的圆角控件 |
| 布局容器及组合 | 轴向、对齐、分布、间距、换行 | 纵横向使用 flex；叠放使用 grid 且隐藏无意义分布/间距；水平布局显示换行 |
| 商品 | SKU、价格模式、示例字段、选择组、默认选中、默认/选中状态样式 | SKU 从中央商品数据读取；同组默认值互斥；修改默认值清除旧临时选择；选中态使用完整通用视觉字段集 |
| 按钮 / 购买按钮 | 动作、链接、页面、弹层 | 无动作不产生副作用；链接仅 http/https；页面切换归属实际 Flow；弹层打开/返回正确；支付类动作仅预览提示 |
| 标签按钮 | 目标标签页、对应页面、选中背景/文字 | 页面选项来自目标实际子节点；点击/键盘切页；未单独设色的子文字继承选中颜色 |
| 标签页 / 多页面流程 | 默认页面 | 显示实际选中子页面；更改默认页面不会继续被旧临时状态覆盖 |
| 轮播 | 默认页、自动切换、间隔、循环 | 交互预览才自动计时；支持循环与末页停止；手动分页有效 |
| 开关 | 默认状态 | 控制实际关闭/开启分支，与关联控件状态一致 |
| 开关控件 | 类型、初始状态、购买前必勾选 | 关联开关时不提供冲突初始值；购买只检查当前可见分支的协议 |
| 倒计时 | 时长、预览分支、子文字计时字段 | 合法时间实际计时；非法值进兜底，零时长进结束；时/分/秒绑定不会再被富文本或 SKU 遮蔽 |
| 快捷结账 | 可用/不可用/加载中 | 切换真实状态子层，不执行交易 |
| 钱包按钮 | Apple Pay / Google Pay | 更新按钮名称；点击与键盘均给出未发起真实交易的提示 |
| 自定义网页 | HTML | 隔离 iframe；脚本不能访问父页面，不冒充原生交易组件 |
| 页头 / 页脚 / 底部弹层 | 通用样式及可编辑子组件 | 固定区域/弹层语义保留；页头页脚只在所属页面生效 |
| 标签页面、标签按钮组、轮播页、时间线及节点、状态内容 | 通用布局与样式、真实子组件 | 不是额外黑盒；结构身份由父组件管理，不重复配置同一份内容 |

## 执行方式与待验收

`npm test` 包含 `tests/componentProperties.test.js`：57 项新增测试，覆盖 30 类节点与 27 项专项交互；其中直接挂载完整编辑器的测试执行选择图层、改内容/字号/边距、自动保存、卸载后重新打开并读回预览。

上述自动化证据不覆盖浏览器布局引擎，不能据此把“所有像素无缺陷”标为已验收。浏览器恢复后仍需检查 390×844 画布、窄宽工作台、真实滚动、横向填满/边距组合、图片完整显示、页脚/弹层和四张 HT 模板视觉；已发生的访问拒绝单独记录在私有工作流台账，不纳入公开源码。

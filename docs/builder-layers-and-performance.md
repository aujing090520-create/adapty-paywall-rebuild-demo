# 单组件树编辑器

## 当前决策

2026-10-23：用户明确以 RevenueCat 的组件结构为最高优先级，允许调整四个 HT 模板的内部结构，要求保留其素材、文案、商品数据。旧的“从专用模块投影图层、再回写旧配置”方案已退出编辑器。

- 唯一编辑文档：`Screen -> Stack / 业务容器 -> 基础元素`。节点真实持有 children 与 props。
- 图层、预览、属性面板、复制、排序、跨容器移动和保存都操作同一文档。
- 商品是 Package；标签、名称、价格、说明为独立子节点。不再提供五种专用商品布局切换。真实父容器决定横向、纵向、叠放、尺寸、间距、对齐。
- SKU 与价格运算集中管理；绑定文字读取所属 Package 的商品数据，可显式转为独立文字。
- Tabs、Carousel、Flow、Timeline 保留行为及类型约束，不降级为无行为的 Stack。Countdown 保留 HT 倒计时业务。
- 挽留弹窗是独立展示容器，默认不混入页面流，选中其图层可定位编辑。
- 蓝色特权详情转为 Flow 的真实 Screen，权益行按钮跳转对应页面。保留原多语言 Key，不把 Key 当作用户文案。

## 迁移与保存

旧节点只用于首次导入。`paywall-component-document-v3:<templateId>` 保存规范文档，后续优先加载它，不再反编译至 v1。每模板独立保存，250ms 合并写入，页面离开与编辑器卸载时刷新保存。

四个 HT 模板以其 v1 已保存节点或自身源定义作为首次迁移输入。创建页默认商品不再隐式覆盖模板商品。v1 记录和素材文件不删除、不覆盖为新格式；无效 v3 记录显示错误并禁止覆盖。重置同时清理本 Demo 的 v1/v3 配置及组件库，不清理其他站点数据。

v3 组件库保存实际子树与样式，不保存 SKU、商品数据记录或价格绑定所有权。绑定文字以保存时预览文案存为独立文字。插入时重建节点 ID 及内部标签引用。旧 v1 组件库仍留在本地，不作为 v3 子树直接读取。

## 来源与边界

结构依据用户 RevenueCat Layers 截图、已采集编辑器记录及上轮现场核对的 Multi-tier 1 层级。导入沿用现有采集数据，不代表本轮重新采集全部源端隐藏属性，也不代表 RevenueCat 私有 schema 或全部模板视觉已像素级等价。第38张、真实SKU后端、Billing交易与关闭行为仍排除。

Figma/HT 素材优先级不变，未修改素材文件。四模板媒体分别为 blue-banner、member-hero、recovery-bg、sku-art-alt。参考截图没有当作新渲染输出。

## 已验证路径

- 45 个模板能导入有效且 ID 唯一的树，源对象不变。
- 四个 HT 模板保留3/3/2/2商品及独立SKU、素材；隐藏权益行与详情资料保留。
- 单价格文字字号、颜色、父容器及同级次序可变，其他商品不变，移动不改变文字尺寸。
- 蓝色商品名称对齐；切换选中前三个商品框体尺寸不变，标签独立。
- Multi-tier 两页标题、权益、商品独立，切换实际更换内容与价格。
- Mindful moments 第2页使用第2张插画，Multi-step 按原动作前进至第2/3页。
- 新增容器和文字后保存、重开回读、组件库保存/插入/删除经本地浏览器检查。

## 修改效率

编辑器不再同时维护投影树、专用面板和专用商品布局三套编辑分支，App 删除约250行旧工作区逻辑。模板与画廊独立缓存。编辑直接写规范树，不再查询旧商品 DOM 几何来反推结构。

构建仍约1.5秒，没有宣称倍数加速。Fast Refresh、画廊延迟挂载、翻译批处理沿用已通过实现。命令：`npm run test:builder`、`npm test`、`npm run build`。自动测试不替代逐模板视觉验收。

## 组件目录与图层操作

来源：2026-10-23现场读取 Talkin Multi-tier 1 研究草稿的 Add component 和图层更多菜单，并核对 [RevenueCat 组件文档](https://www.revenuecat.com/docs/tools/paywalls/creating-paywalls/components)。目录入口会直接新增，不能当作只读预设浏览器。本轮试点新增的一个空 Package 已定点删除，源端恢复2个商品且确认 Changes saved as a draft，未发布。

| 分类 | 本地目录 | 文档模型与边界 |
| --- | --- | --- |
| 基础 | 文字、图片、视频、图标、布局容器、页头、页脚、自定义网页 | 原子元素与容器；页头/页脚只属于页面，各限制一个；Custom为sandbox隔离HTML/CSS/JS预览，不模拟RevenueCat ZIP分发或SDK桥接 |
| 付费墙 | 商品、底部弹层、购买按钮、快捷结账 | Package持有商品记录；底部弹层是按钮导航到真实Sheet；快捷结账包含可用/不可用/加载三个子层及钱包按钮，按用户要求仅交易预览 |
| 交互 | 标签页、开关、按钮、轮播 | 标签页面/按钮组、OFF/ON状态内容、轮播页均为真实子节点，可独立放入组件 |
| 内容 | 倒计时、时间线、口碑展示、权益列表、奖项展示 | 倒计时包含计时/结束/兜底子层及时间字段；后三者按官方语义是普通Stack预设，展开后继续编辑基础元素 |

页面、轮播页、标签页面、结账状态、开关状态、倒计时状态不作为通用目录中的自由组件，只在正确父层中添加。保存模型保留原有Flow扩展，不将它混入RevenueCat核心目录。

图层行中的加号明确绑定该容器，不依赖右侧当前选中项。更多菜单支持：重命名、包入布局容器、编辑器内复制/粘贴、创建副本、上下移、复制/粘贴样式、隐藏/显示、删除。根页面禁止删除或隐藏。菜单挂在工作区滚动容器之外，避免再次被底部或面板裁切。

复制组件时重建节点、内部跳转和商品数据记录的键，避免改副本影响原商品。样式复制包含实际默认值，但不包含文字、动作、媒体src及SKU绑定。编辑器剪贴板仅在本应用内使用，可跨模板粘贴，不读取系统剪贴板。

既有倒计时首次加载时补为可编辑子树，保留原时长、前缀、颜色和数字底色；原模板素材及SKU不变。四个HT模板依然从同一组件模型扩展，不添加模板专用入口。旧模板v1数据不清空。

新增代码按职责分开：`componentCatalog.js`只管目录与组合；`ComponentPicker.jsx`只管添加面板；`componentOperations.js`只管可测试的复制、样式和包裹操作；`LayerActionsMenu.jsx`只管上下文菜单。不要把整张新模板封装成无法拆分的专用组件。

## 页面与组件树修正

不能把首页与17个权益详情页面当作同级业务模块全部摊开。Flow内以“当前页面”选择器切换真实Screen，只展开当前页面的真实子树；其他页面仍保留在同一文档中，未删除或合并。预览内打开详情/返回也同步页面选择器。Flow是已有多页能力，不作为RevenueCat基础组件冒充。

初次进入时页面/流程保持展开，模块容器默认收起。每行显示实际组件类型和相应图标；收起时摘要按直接子组件类型计数，不虚构额外节点。例如“商品选择”显示“布局容器 / 商品 × 3”，展开后是原有3个Package，各自再展开到文字等真实节点。布局、文字、图片、SKU仍由同一canonical tree管理。

拆分倒计时的Text默认使用fit宽度，避免横向布局把数字和前缀等分为填满宽度的槽位。既有记录仅在这些Text未显式配置widthMode时修复；手动固定宽度与字号不覆盖。

| 问题 | 修正 | 验收 |
| --- | --- | --- |
| TREE-01 首页折叠后只剩详情页，模块归属混乱 | 页面选择器与当前页面树分开 | 首页/详情切换及预览跳转同步 |
| TREE-02 类型图标混用，模块组成不可辨认 | 真实类型图标、类型文字、折叠组成摘要 | 商品组、主视觉等展开对应原始子节点 |
| TREE-03 拆分倒计时拉伸换行 | 默认fit子项及兼容修复 | 紧凑单行，保留显式宽度/字号 |

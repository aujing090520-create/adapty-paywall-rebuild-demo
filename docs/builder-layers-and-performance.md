# 单组件树编辑器

## 当前决策

2026-10-23：用户明确以 RevenueCat 的组件结构为最高优先级，允许调整四个 HT 模板的内部结构，要求保留其素材、文案、商品数据。旧的“从专用模块投影图层、再回写旧配置”方案已退出编辑器。

- 唯一编辑文档：`Screen -> Stack / 业务容器 -> 基础元素`。节点真实持有 children 与 props。
- 图层、预览、属性面板、复制、排序、跨容器移动和保存都操作同一文档。
- 商品是 Package；标签、名称、价格、说明为独立子节点。不再提供五种专用商品布局切换。真实父容器决定横向、纵向、叠放、尺寸、间距、对齐。
- SKU 与价格运算集中管理；绑定文字读取所属 Package 的商品数据，可显式转为独立文字。
- Tabs、Carousel、Flow、Timeline 保留行为及类型约束，不降级为无行为的 Stack。Countdown 保留 HT 倒计时业务。
- 挽留弹窗是独立展示容器，默认不混入页面流，选中其图层可定位编辑。
- 蓝色特权详情转为 Flow 的真实 Screen，权益行按钮跳转对应页面。保留原多语言 Key，不把 Key 当作用户文案。

## 迁移与保存

旧节点只用于首次导入。`paywall-component-document-v3:<templateId>` 保存规范文档，后续优先加载它，不再反编译至 v1。每模板独立保存，250ms 合并写入，页面离开与编辑器卸载时刷新保存。

四个 HT 模板以其 v1 已保存节点或自身源定义作为首次迁移输入。创建页默认商品不再隐式覆盖模板商品。v1 记录和素材文件不删除、不覆盖为新格式；无效 v3 记录显示错误并禁止覆盖。重置同时清理本 Demo 的 v1/v3 配置及组件库，不清理其他站点数据。

v3 组件库保存实际子树与样式，不保存 SKU、商品数据记录或价格绑定所有权。绑定文字以保存时预览文案存为独立文字。插入时重建节点 ID 及内部标签引用。旧 v1 组件库仍留在本地，不作为 v3 子树直接读取。

## 文件职责

| 文件 | 当前职责 |
| --- | --- |
| `src/builder/componentDocument.js` | 文档操作、一次性导入、类型约束、SKU 绑定、保存和复制 |
| `src/builder/ComponentEditor.jsx` | 真实图层、统一属性面板、结构编辑、组件库、本地保存 |
| `src/builder/ComponentPreview.jsx` | 仅渲染规范树，维护商品/标签/轮播/流程预览状态 |
| `src/builder/componentEditor.css` | 独立编辑器样式，不依赖旧专用商品布局 CSS |
| `src/App.jsx` | 工作区及模板选择，编辑器直接使用 ComponentEditor |
| `src/templates/templateDefinitions.js` | 首次导入源和画廊元数据，非第二套活动编辑文档 |
| 旧预览与产品模块 | 旧画廊预览及导入辅助，不驱动当前编辑器 |

## 来源与边界

结构依据用户 RevenueCat Layers 截图、已采集编辑器记录及上轮现场核对的 Multi-tier 1 层级。导入沿用现有采集数据，不代表本轮重新采集全部源端隐藏属性，也不代表 RevenueCat 私有 schema 或全部模板视觉已像素级等价。第38张、真实SKU后端、Billing交易与关闭行为仍排除。

Figma/HT 素材优先级不变，未修改素材文件。四模板媒体分别为 blue-banner、member-hero、recovery-bg、sku-art-alt。参考截图没有当作新渲染输出。

## 已验证路径

- 45 个模板能导入有效且 ID 唯一的树，源对象不变。
- 四个 HT 模板保留3/3/2/2商品及独立SKU、素材；隐藏权益行与详情资料保留。
- 单价格文字字号、颜色、父容器及同级次序可变，其他商品不变，移动不改变文字尺寸。
- 蓝色商品名称对齐；切换选中前三个商品框体尺寸不变，标签独立。
- Multi-tier 两页标题、权益、商品独立，切换实际更换内容与价格。
- Mindful moments 第2页使用第2张插画，Multi-step 按原动作前进至第2/3页。
- 新增容器和文字后保存、重开回读、组件库保存/插入/删除经本地浏览器检查。

## 修改效率

编辑器不再同时维护投影树、专用面板和专用商品布局三套编辑分支，App 删除约250行旧工作区逻辑。模板与画廊独立缓存。编辑直接写规范树，不再查询旧商品 DOM 几何来反推结构。

构建仍约1.5秒，没有宣称倍数加速。Fast Refresh、画廊延迟挂载、翻译批处理沿用已通过实现。命令：`npm run test:builder`、`npm test`、`npm run build`。自动测试不替代逐模板视觉验收。

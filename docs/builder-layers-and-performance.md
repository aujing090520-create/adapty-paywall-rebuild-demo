# 组件层级与修改效率

## 本次边界

将编辑入口改为页面、容器、业务组件、基础元素的层级；保留现有渲染和数据绑定，通过字段适配读写旧配置，不把旧模板先清空再重建。四个 HelloTalk 模板的保护 ID、原始素材和本地保存键不变。真实交易、SKU 后端接入、关闭行为和第 38 张模板不在本次范围。

- 本次未替换模板图片或调整原有视觉基线；后续视觉调整仍以已提供 Figma 优先。

## 各类组件如何拆分

| 现有类型 | 层级与职责 | 实际编辑入口 |
| --- | --- | --- |
| 页面 / 多页面流程 | 流程 → 页面 → 容器与元素 | 选择页面定位预览；保留步骤切换动作 |
| 页面背景 | 页面根层的背景，不占普通内容流 | 原背景媒体设置 |
| Stack / Card | 容器 → 原有真实子节点 | 添加子组件、拖入容器、同级排序；禁止循环嵌套 |
| 标题 / 正文 / 富文本 | 文字 → 已有富文本片段 | 原文字样式；片段直接修改，保留相邻片段 |
| 主视觉 | 主视觉容器 → 媒体、标题组合、说明 | 原素材预览与替换；文案独立绑定 |
| 图片 / 视频 / 图标 | 基础元素 | 原媒体和图标属性 |
| 商品套餐 | 套餐组 → 商品 → 当前布局区域 → 实际显示的字段 | SKU 字段保持绑定；单商品字段字号/颜色；区域内排序及区域间移动 |
| 列表 | 列表 → 项目容器 → 图标、标题、实际说明 | 字段编辑、项目排序、删除、父级新增 |
| 特权对比 | 列表 → 实际可见权益行 → 名称、非会员权益、会员权益 | 区分文字与锁/勾选图标；保留隐藏行配置 |
| 权益表格 | 表格 → 表头 / 行 → 单元格文字 | 原表格设置及单元格绑定 |
| 时间线 | 时间线 → 时间节点 → 标记、标题、说明 | 不破坏节点次序与连线关系 |
| 标签页 | 标签页 → 页面 → 标题、全部标签按钮、权益、商品 | 选中子层自动切换预览；页面权益文案独立存储 |
| 轮播 | 轮播 → 轮播页 → 图片、标题、说明 | 选中子层定位对应页，支持替换及页排序 |
| 普通开关 | 开关 → 文字、开关控件 | 保留关联商品组，不伪装成第二套标签页 |
| 按钮 / 购买按钮 / 网页购买 | 业务按钮 → 文字 | 文字子层与动作配置分离，购买绑定不拆掉 |
| 链接组 | 链接组 → 按钮 → 文字 | URL 属于按钮属性，不新增虚构 URL 视觉节点；恢复购买不要求 URL |
| 同意协议 | 协议 → 勾选框、协议片段 → 文字 | 链接地址归片段属性，保留勾选 gating |
| 倒计时 | 倒计时 → 实际前缀、数字、实际后缀 | 保留计时逻辑，不把数字拆成静态文字 |
| 口碑展示 | 评分、数量、实际说明、实际装饰图 | 已有数据绑定，不凭空增加空图片层 |
| 奖项 | 奖项容器 → 实际装饰图、奖项文字组合 | 保留组合样式，文字分别修改 |
| 页脚 / 法律文字 | 保留原有容器及富文本链接 | 不改变法务文案及链接行为 |

内部 `layerModel.js` 使用稳定的 owner / path 绑定，层级视图本身不复制一份内容。列表等旧数组只在编辑时按需写入，原配置可继续加载。区域排序继续走统一布局规则，不恢复任意 X/Y 坐标。不同商品的单项文字样式位于 `config.packagePartStyles[index][part]`，统一样式仍作为默认值。

这是兼容层级编辑模型，不是 RevenueCat 私有 schema 的直接导入，也不承诺其所有属性面板已完整移植。

## 实测与后续修改路径

- 原入口约 413KB，包含模板、配置面板、渲染和状态。拆分后入口仅 6 行，状态页不再同时承担全部配置与模板定义。
- 原构建约 1.5–2 秒，本次最终构建仍在这一量级。打包不是主要瓶颈，不声称构建获得倍数提升。
- 最终生产文件拆为业务 311.35KB、模板 190.86KB、依赖 170.31KB。总 JS 大小没有减少；收益是稳定模板与依赖可独立缓存，局部业务变更不再使整个约 673KB JS 包失效。
- 启用 React Fast Refresh。现场修改独立子属性面板后，仍停留在原模板、同一商品价格层，未丢失编辑状态；开发日志出现该模块的 hot updated。
- 模板弹窗 45 个卡片保持不变，实测首次可见区域只挂载 5 个付费墙预览；其余接近可见区域时再挂载。固定预览尺寸不因等待素材改变。
- 本地模板写入合并为 250ms；切换模板原有同步保存保留，页面离开时刷新待保存内容。
- 翻译监听合并同一批 DOM 变化，翻译自身引起的变化不再触发整页重复扫描。
- 原全局 CSS 仍较大，未为了减行数重排其层叠顺序；新图层样式单独维护。

常规命令：`npm run test:builder` 检查层级/保存；`npm run test:products` 检查商品；`npm test` 执行全套。只改变局部配置时，浏览器验证受影响路径；共享模型或跨组件改动仍执行全套，不以提速为由跳过必要验证。

## 本轮验收

1. 57 项自动测试通过，包含全模板层级唯一性、默认节点不被改写、SKU 隔离、容器循环防护、子内容绑定、标签页独立文案与共享角标占位。
2. 浏览器实际修改蓝色特权首行文字，预览立即变化，随后恢复原文案。
3. 浏览器实际把第二商品价格字号由 18 改为 24；仅第二项像素字号从约 14.31 改为 19.08，第一/三项保持约 12.72；恢复后回到原值。
4. 热更新独立属性面板后，编辑模板及已选价格层保持，开发日志为单模块 hot updated。
5. Multi-tier 1 的 Standard 权益修改不影响 Premium，切换子层同步定位正确页面，测试文案已恢复。
6. Mindful moments 选择第三页标题子层，预览定位到页码 2，标题修改实际回显并恢复。
7. 四个 HT 模板分别读取到 blue-banner、member-hero、recovery-bg、sku-art-alt 原素材路径，套餐数量分别为 3、3、2、2。没有修改素材文件。
8. 模板弹窗无横向溢出；45 卡片中首次可见区域只挂载 5 个预览。相关编辑路径无控制台错误。

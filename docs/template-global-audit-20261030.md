## 页头修复

- 4 张 HelloTalk 模板：蓝色特权页、会员套餐页、支付未完成页、SKU 半窗均有固定导航页头。

- 原有叠在主视觉上的按钮继续覆盖正文；普通标题行继续占据页头空间。页头属性中的“覆盖正文”可以切换这两种布局。
- 手动新增关闭/返回按钮时复用同一页头，不再生成随正文滚动的导航行。
- 保留按钮 ID、图标、动作和按钮下的弹窗绑定；不凭空新增第二个关闭按钮。
- 本次固定导航是 Demo 可用性修复，不代表参考站所有原始 Stack 都是固定 Header，也不宣称已完成不可访问项目的像素级对齐。

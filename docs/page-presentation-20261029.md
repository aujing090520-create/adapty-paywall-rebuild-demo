# Paywall 页面展示与滚动边界

## 配置归属

- 所有模板都有 Screen 页面根节点；内部 Stack 不决定整个 Paywall 的展示形态。
- 点击画布工具栏“页面展示”定位当前 Screen，并将右侧面板滚到“页面展示 / 展示方式”；可选全屏页面、底部半窗或居中窗口。面板滚动不移动外页或画布。
- 多步骤逐屏独立配置；按钮打开的 BottomSheet 仍属于按钮，不因页面形态切换改变触发关系。
- 窗口高度、边距和圆角只在窗口模式显示；切到全屏保留参数，切回恢复。
- 显式页面形态管理外框，隐藏根节点通用宽高，内部布局容器保留自己的尺寸能力。

## 兼容处理

- 旧会员套餐、支付未完成、SKU 半窗通过 `$scene` 顶部留白模拟半窗；转换为真实页面窗口外框，不再用内部容器高度模拟。
- 保留内容节点ID、商品配置、动作与页脚；回收旧模拟层的顶部留白与外框高度。支付恢复背景图片保留为窗口背景节点，不删除媒体。
- 普通全屏文档不因读取默认展示方式而写入新属性；用户选择模式后才保存。
- “添加关闭/返回按钮”优先定位已有同类导航，支持在轮播等嵌套内容中查找，但不跨越弹窗或其他屏幕。
- 对三个HT半窗中“默认关闭按钮 + 生成导航栏内重复的纯Dismiss图标”清理后者；不同动作、弹窗绑定或包含其他内容的按钮不自动删除。

## 验证

- 834 项测试全部通过，包含45个模板的页面归属、双向切换、保存读取、内容与商品保留，以及重复导航回归；旧半窗作为新增流程步骤导入时也先转换页面展示配置。
- 本地真实浏览器：SKU窗口500px时可从0滚到119；外层视口不滚动。
- 会员窗口715px：手势将正文从0滚到56，页脚top保持830.540；外层视口与画布scrollTop均保持0。
- 会员半窗、全屏只有一个模板关闭按钮；模式切换不新增按钮。
- 原有用户记录没有通过测试被保存、替换或删除；浏览器验证使用未创建的新建草稿。

## 边界

- 此为 Demo 画布与交互预览的页面呈现，不代表已对接原生SDK的系统模态转场或真实支付。
- 两个关闭按钮若绑定不同动作会保留，避免静默丢失用户配置。

# 蓝色特权页：购买按钮右上角角标

## 配置入口

新建或重新应用“蓝色特权页”，展开“页脚”，选中“购买按钮”，在右侧“徽标”模块配置。角标直接归属购买按钮，不新增布局容器或文字图层，也不改变按钮点击动作。

默认已启用，位置为“右上”，样式为“覆盖边框”，橙色胶囊、白色文字。正文、倒计时、套餐与按钮配色保持原模板配置；这里只参考提供截图的按钮角标。

## 文字与样式边界

- 按钮和购买按钮的徽标文字只读，固定显示 `{按钮标签类型}`。不再提供文案编辑、富文本编辑或插入变量入口。
- 可编辑的仅为样式，包括字体、字号、字重、颜色、文字背景、位置、内外边距、形状、圆角、填充、边框及阴影。徽标启用状态仍可切换。
- 旧记录即使保存了其他文案或富文本，也统一预览为 `{按钮标签类型}`，保留原来的样式；不要求重新套用模板。
- 不再为新蓝色模板添加示例 `savings_amount` 业务变量。旧记录已有的业务变量不删除，以免影响其他文字引用。
- 实际按钮标签由外部业务配置提供；本 Demo 只展示字段占位，不新增真实接口或真实金额计算。

## 边界

只为蓝色特权页新增默认角标；其他模板不默认添加。所有模板中的按钮徽标采用同一个只读占位规则。商品标签、普通文字及非按钮容器原有的通用徽标能力不在本次修改范围。

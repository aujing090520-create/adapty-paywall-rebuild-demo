# 蓝色特权页：购买按钮右上角角标

## 配置入口

新建或重新应用“蓝色特权页”，展开“页脚”，选中“购买按钮”，在右侧“徽标”模块配置。角标直接归属购买按钮，不新增布局容器或文字图层，也不改变按钮点击动作。

默认已启用，位置为“右上”，样式为“覆盖边框”，橙色胶囊、白色文字。正文、倒计时、套餐与按钮配色保持原模板配置；这里只参考提供截图的按钮角标。

## 文字及变量

- 固定文案：直接将“徽标文字”改成“限时优惠”等文案。
- 变量混排：使用“插入变量”，可以选择商品变量或工作区中已定义的业务变量。购买按钮上的商品变量读取当前选中套餐；套餐内部角标读取所属套餐。
- 默认示例：`节省{{ business.savings_amount }}`。蓝色模板的工作区配置中预置了文字变量 `savings_amount`，默认值是 `{节省金额}`，所以画布显示“节省{节省金额}”，不使用真实 SKU 价格。
- 业务变量位置：“工作区配置 → 条件与联动 → 业务变量”。可以编辑默认值、添加变量；改名会同步引用。金额变量应提供带币种的格式化文字，不在此角标另算折扣、节省比例或汇率。
- 当前是 Demo 本地数据与变量渲染，没有因此新增真实业务接口。生产接入时由业务数据提供变量值。
- 完全空白或变量整段没有可用值时，不绘制空的角标；关闭“徽标”会隐藏且保留文案，重新启用可以恢复。

## 边界

只为蓝色特权页新增默认角标；其他模板不默认添加。已有个人记录不被模板默认值覆盖，可以在原购买按钮上手动启用同一个“徽标”模块并配置。支持固定文字与变量的编辑器能力适用于其他已有徽标入口。

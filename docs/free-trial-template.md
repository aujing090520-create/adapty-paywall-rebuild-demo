# HelloTalk 免费试用页

## 使用入口

创建付费墙 → 选择模板 → **HelloTalk 免费试用页** → 在构建器中打开。确认样式后回到创建页，再填写名称并创建记录。既有记录和其他模板默认值不变。

本模板使用现有组件，新增组件类型为 **0**。一个全屏 Screen 内包含 Header、三页 Carousel 和固定 Footer，不是三个独立的购买屏幕。

## 结构与配置归属

| 区域 | 现有组件 | 配置位置 |
| --- | --- | --- |
| 主视觉 | Header → Stack → Image、Text | 替换独立插画；标题保持可编辑文字 |
| 关闭入口 | Header → Button → Icon、BottomSheet | 按钮行为打开自己的挽留弹窗 |
| 权益介绍 | Carousel → Slide → Stack、Icon、Text | 每行图标、标题、副文案分别编辑 |
| 到期提醒 | Carousel → Slide → Timeline、TimelineItem | 今天、结束前一天、第 3 天，分别可编辑 |
| 套餐选择 | Carousel → Slide → Stack → Package | 同一选择组内年度试用与月度直接购买 |
| 商品字段 | Package → ProductParameter | SKU 时长、划线总价、月价、商品信息使用占位字段，不读取真实价格 |
| 分页指示 | Carousel → PageControl → Indicators | 使用现有原生分页及横向手势 |
| 购买区域 | Screen → Footer → PurchaseButton、Text、Button | 固定页脚；条款和隐私是独立链接 |
| 挽留内容 | 关闭 Button → BottomSheet | 独立图片、标题、副文案、继续及离开按钮 |

## 交互规则

1. 前两页点击“0元领取3天VIP体验”直接发起年度试用套餐的**模拟购买**，不先跳到第三页。通过购买按钮的“购买商品”选择指定年度套餐实现。
2. 第三页默认年度试用。其购买按钮“购买商品”为“跟随当前选中套餐”；选择月套餐后，按钮变为“继续”，取消提示及续订文案一并切换。
3. “条件与联动”使用“当前组件页面”和“选中商品套餐”，按组件 ID、页面 ID 与套餐 ID 关联，不依赖页面数组位置或实际 SKU。
4. 关闭图标打开自己绑定的挽留底部弹窗。“不，我不放弃”返回当前页并保留选择；“是，暂时不用”结束预览。
5. `business.trial_days` 默认 3，`business.renewal_price` 默认 `¥{总价}`。这些仅为 Demo 配置，不代表实际试用资格、续费金额或真实业务接口。

### 在其他模板配置同类按钮联动

这不是免费试用页专属代码。普通 Button、购买 PurchaseButton 和其 Text 子组件都使用同一套联动规则：

1. 打开画布工具栏“条件与联动”，添加规则。
2. 条件类型选择“选中商品套餐”，选择触发联动的套餐，不需要绑定真实 SKU。
3. 若仅换文案，影响节点选按钮内的文字，联动行为选“替换文字”。若需要切换不同按钮或购买路径，分别给对应按钮配置“显示 / 隐藏”；也支持“禁用 / 启用按钮”。
4. 购买按钮的“购买商品”选择“跟随当前选中套餐”。只有需要前两页始终购买试用套餐时，才选择“指定套餐”。

规则不命中时恢复组件自身的默认文字、显示及可用状态；切换预览不会改写模板保存值。按钮徽标独立于上述联动，固定展示 `{按钮标签类型}`，不作为按钮正文使用。

## 通用能力补充

- 购买按钮新增可选的 `action.packageId`，默认仍跟随选择。可以引用同屏、同弹窗范围中非当前轮播页的套餐；隐藏、条件隐藏、非当前开关分支、删除、跨屏及跨弹窗的指定套餐不允许购买。无效指定目标不静默退回其他套餐。
- 整屏复制时同步重映射购买目标、页面条件、套餐条件与选择组，保留副本的默认年度选中，不影响原屏。
- 有界 Carousel 的页包装增加纵向 Flex 约束，使填满高度的 Slide 正常占用空间。固定高度和自适应页面沿用已有配置。
- 模板卡片直接渲染原生组件文档，不使用整页参考截图作为缩略图。

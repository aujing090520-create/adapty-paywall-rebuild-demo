# HelloTalk 免费试用页

## 使用入口

创建付费墙 → 选择模板 → **HelloTalk 免费试用页** → 在构建器中打开。确认样式后回到创建页，再填写名称并创建记录。既有记录和其他模板默认值不变。

本模板使用现有组件，新增组件类型为 **0**。一个全屏 Screen 内包含 Header、三页 Carousel 和固定 Footer，不是三个独立的购买屏幕。

## 结构与配置归属

| 区域 | 现有组件 | 配置位置 |
| --- | --- | --- |
| 主视觉 | Header → Stack → Image、Text | 替换独立插画；标题保持可编辑文字 |
| 关闭入口 | Header → Button → Icon、BottomSheet | 按钮行为打开自己的挽留弹窗 |
| 权益介绍 | Carousel → Slide → Stack、Icon、Text | 每行图标、标题、副文案分别编辑 |
| 到期提醒 | Carousel → Slide → Timeline、TimelineItem | 今天、结束前一天、第 3 天，分别可编辑 |
| 套餐选择 | Carousel → Slide → Stack → Package | 同一选择组内年度试用与月度直接购买 |
| 商品字段 | Package → ProductParameter | SKU 时长、划线总价、月价、商品信息使用占位字段，不读取真实价格 |
| 分页指示 | Carousel → PageControl → Indicators | 使用现有原生分页及横向手势 |
| 购买区域 | Screen → Footer → PurchaseButton、Text、Button | 固定页脚；条款和隐私是独立链接 |
| 挽留内容 | 关闭 Button → BottomSheet | 独立图片、标题、副文案、继续及离开按钮 |

## 交互规则

1. 页脚始终只有一个购买按钮。其“购买商品”设为“按组件页面配置”，默认购买年度试用套餐。前两页点击直接发起年度试用套餐的**模拟购买**，不先跳到第三页。
2. 同一按钮为第三页单独配置“跟随当前选中套餐”。第三页默认年度试用；选择月套餐后，按钮变为“继续”，取消提示及续订文案一并切换。回到前两页后恢复年度试用目标与文案，不会误买月套餐。
3. 按钮文字由购买按钮自身的“按钮文案”配置持有，不依赖工作区文字替换规则。“条件与联动”仅保留页面显隐、取消提示和续订提示规则。
4. 关闭图标打开自己绑定的挽留底部弹窗。“不，我不放弃”返回当前页并保留选择；“是，暂时不用”结束预览。
5. `business.trial_days` 默认 3，`business.renewal_price` 默认 `¥{总价}`。这些仅为 Demo 配置，不代表实际试用资格、续费金额或真实业务接口。

### 在其他模板配置同类按钮联动

这不是免费试用页专属代码。普通 Button 和购买 PurchaseButton 都有同一个组件内配置入口：

1. 选中按钮，在右侧“按钮文案”中，将“文案切换方式”设为“按选中套餐切换”。
2. 选择要关联的套餐选择组，在“配置套餐文案”中选择默认或某个套餐，直接编辑对应文字。不需要真实 SKU，也不需要另建工作区规则。
3. 未单独配置的套餐沿用默认文案；“恢复默认文案”可移除单个套餐覆盖。固定模式与套餐模式可相互切换，保留已配置内容。编辑态选择某个文案方案时，画布同步显示该方案；交互预览仍跟随用户实际选中的套餐。
4. 一般场景“购买商品”选择“跟随当前选中套餐”。共享页脚在不同轮播页需要购买不同目标时，选择“按组件页面配置”，设置默认目标并逐页覆盖；不需要复制第二个按钮。

按钮文字子层继续控制字体、颜色和排版，但内容统一回到所属按钮配置，不再提供第二份可编辑正文。旧免费试用记录的套餐文字规则会按原值迁移进按钮，保留其余提示规则，不覆盖已有组件内自定义值。切换顶部内容语言后，可在同一按钮配置中编辑译文，缺少译文回退默认。按钮徽标独立于上述联动，固定展示 `{按钮标签类型}`，不作为按钮正文使用。

## 通用能力补充

- 购买按钮可选 `action.packageId`，默认跟随选择。`action.pagePackages` 可让同一个按钮按轮播/标签页身份切换目标，并在不同购买方式间保留页面配置。可以引用同屏、同弹窗范围中非当前轮播页的套餐；隐藏、条件隐藏、非当前开关分支、删除、跨屏及跨弹窗的指定套餐不允许购买。分页组件失效或指定目标无效时阻止购买，不静默改买其他商品。
- 整屏复制时同步重映射购买目标、页面条件、套餐条件与选择组，保留副本的默认年度选中，不影响原屏。
- 有界 Carousel 的页包装增加纵向 Flex 约束，使填满高度的 Slide 正常占用空间。固定高度和自适应页面沿用已有配置。
- 模板卡片直接渲染原生组件文档，不使用整页参考截图作为缩略图。

# 商品礼包交互修复

## 问题与范围

- 切换无礼包套餐：礼包区消失后，内容高度缩短，浏览器钳制内部滚动位置，商品区域跳动。
- 礼包说明：原来展开内联说明，会改变页面高度，改为点击图标显示悬浮气泡。
- 不改变模板商品、SKU 数据、默认选中套餐、商品组件或页脚归属。

## 实现

- 套餐鼠标及键盘选择前记录最近内部滚动区的位置；布局完成后补足保持当前视口所需的临时底部滚动余量，恢复位置。
- 余量不是礼包占位组件，不出现在图层或存储配置里；向上滚动时逐步回收，切回有礼包后移除，预览卸载时清理。
- 无礼包仍完全不渲染商品礼包，不提供空说明入口。
- 礼包说明复用独立的 InfoPopover 浮层实现，沿用已有“礼包说明”字段，无额外文案数据源。
- 气泡限制在所属手机预览中，在底部自动向上显示；再次点击、点击外部、Escape、页面滚动、切换套餐或退出预览时关闭。
- 编辑模式点击仅选中组件，不激活说明气泡。

## 验证

- 原问题：375 x 812 实际渲染，内容高度 811 -> 654，scrollTop 183.33 -> 26.67，商品区域 y 311.17 -> 461.81。
- 修复后：同一场景商品区域 y 311.17 -> 311.81，位移小于 1px；无礼包组件数量为 0。
- 切回有礼包、键盘 Enter 切换、向上滚动释放余量、说明气泡 Escape 与外部点击关闭均通过浏览器验证。
- 气泡出现时商品区域 y 与 scrollTop 不变，没有内联布局高度变化。
- 完整测试 950 项通过，生产构建通过。线上部署和用户网络可访问性分别核验，不以部署成功代替用户访问成功。

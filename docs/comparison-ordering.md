# 特权表展示顺序

选中特权对比表最外层布局容器，在右侧设置“展示顺序”。内部列、单元格和普通容器不提供这个配置。

- 按画布顺序：默认行为，保持图层中配置的顺序。
- 按用户规则：选择排序规则。现有两条规则为明确标注的 Demo 示例，不读取真实用户画像。
- 切回画布顺序不清空已选规则。规则不存在、无有效返回或表格行关联不完整时，回退画布顺序。
- 表头固定，各列依据同一特权标识重排，保留原节点样式、行高、显隐和点击动作。排序不会改写模板图层。

## 接入边界

宿主可向 `ComponentPreview` 传入 `businessOrdering`，由业务服务负责当前用户的排序决策；模板不配置用户特征表达式或任意接口地址。

```js
const businessOrdering = {
  values: {
    'social-first': { order: ['visitors', 'nearby', 'exposure', 'partners', 'translation'] }
  }
};
```

标识分别代表：谁看了我、附近的人、曝光助推、母语语伴、翻译字幕。传入宿主结果时，不再回退 Demo 示例；缺失或无效结果使用画布顺序。重复和未知标识忽略，未返回条目按画布顺序追加，不隐式隐藏内容。

当前范围只开放已有蓝色特权对比表，不新增全局规则管理后台，不实现真实用户接口。其他内容集合后续按各自稳定条目标识接入，不能单独排序表格的一列。

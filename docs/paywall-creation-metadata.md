# 创建页配置边界

创建付费墙仅填写样式类型、样式名称、启用状态。类型使用用户提供的八个分类，与所选模板和SKU数据独立，不按分类自动替换画布。

桌面左侧是三项表单，右侧纵向排列“从空白开始”“选择模板”。窄屏自然排到表单下方。两条入口均校验必填名称，名称为空不可进入；保存时再校验一次。

状态默认禁用。禁用记录保存为Inactive，启用记录保存为Draft，不因启用自动发布为Live。配置保存在paywall.config的styleType/name/enabled三个字段中。

## 已移除的旧创建配置

- 业务类型、公众号、业务场景、描述。
- 整张商品表：商品、优惠、优惠标签、默认选中、推荐标签（两态）、选中按钮文案、按钮标签类型、赠送，以及配套的编辑、复制和删除弹窗。
- offerRows/defaultProductId/products的创建默认值与新记录持久化。
- 没有调用方的linkedPackageNode旧联动函数。
- applyTemplate里点数模板回填旧商品表的特殊逻辑。
- 常规商品摘要从旧config.offerRows读取的回退逻辑。

## 保留的关系

当前原生构建器原本就通过模板文档与Package的dataKey关联document.products。这个关系不删除：SKU、金额、周期、默认选中及卡片内容继续在画布内配置。分类或名称改变，不会重写这些数据。

历史个人记录的旧config数据不批量删除，不强制重排其画布；复制时仅带入三项元信息与完整画布，不再携带旧商品表字段。新建和复制记录的商品摘要只读实际画布。

## 重复配置的具体处理

| 旧重复/冲突 | 唯一职责 |
| --- | --- |
| 图片通用形状与图片遮罩互相覆盖 | 图片遮罩控制裁切，矩形时只显示一个圆角输入 |
| 图标自适应/填满与固定大小竞争 | 图标固定宽高；旧表格填满职责迁移到真实单元格容器，保留原图标 ID |
| 图标通用背景与图标背景竞争 | 只保留可选图标背景；不再显示通用外观与第二个尺寸区 |
| 文字全局字重与旧 bold 标志竞争 | 改字重时清理旧标志；粗体工具是同一字重的快捷操作，与原截图一致 |
| 标签默认面板及另一个选中色表单竞争 | 一个状态切换，编辑同一标准属性字段集 |
| 同一标签选择器在各标签页中独立存样式，切页后配置不一致 | 属性修改和粘贴样式共用一次同步操作；按所属 Tabs、按钮组及按钮目标匹配，文案、数据绑定、商品及跳转配置不随样式复制 |
| 非 Fill 的新尺寸仍保留隐藏上限 | 用户切出 Fill 时清理对应上限、下限及启用标志；旧 HT 正高度约束保留可见兼容入口 |
| 轮播“子项间距”与“页面间距”含义重叠 | 父级普通布局区不再出现在轮播上；页面间距只控制实际滑轨 |
| 购买按钮与普通按钮共用所有动作 | 购买按钮配置结账方式；普通按钮配置动作类别和导航目标 |
| 倒计时日期与动态时长同时生效 | 有目标日期时隐藏旧时长；原 HT 动态时长只作兼容保留 |

## 验收边界与恢复顺序

1. 当前源码与自动化测试可验证已实现字段的事件、输出属性、条件显示、状态与保存回读。新增测试同时检查下拉选择值确实存在于可见选项，避免测试直接触发不存在的选项而误报通过。
2. 45 张模板迁移测试验证原节点、文案、素材、商品数据和表格单元格列宽职责保留；不能证明迁移后的所有浏览器像素完全相同。
3. 原界面连接恢复后，必须先核对本表未闭环项目和全部条件菜单；再补齐真实需要的参数，不能依据本表自己设计未知交互。
4. 之后在 Demo 实际浏览器逐项修改、截图核对四张 HT 模板、测试滚动/滑动/媒体，再执行最终全量回归及正式发布。当前不将这一步标为已完成。

# 入门价格页模板

- 入口：创建付费墙 → 样式类型“入门价格页” → 选择模板 → HelloTalk 入门价格页。
- 全屏 Screen 持有固定 Header 和 Footer。Header 仅有一个关闭按钮；Footer 放倒计时、购买按钮和“随时取消”。商品与权益在滚动正文中，不属于页脚。
- 单个 Package 是购买与选择边界，默认按月价模式显示 ProductParameter 月价及划线月价，无绑定 SKU 或真实金额。可用现有价格模式切换，不新增独立价格输入。
- “首月额外20%优惠！”、“仅限今日”与三项权益使用现有文字、图标和布局组件，可直接修改。皇冠和勾选使用内置图标库，没有把参考图当背景。
- 页脚使用已有 Countdown 组件，默认每次进入从23分59秒开始，以分:秒展示。选中图层“倒计时”可使用现有计时方式、时间来源、样式和商品联动配置；默认不联动商品，结束显示“优惠已结束”并保留正常购买。未连接真实活动接口。
- 已创建的本模板记录若仍保留原始“优惠截止时间 23:59”文字节点，在读取时按模板和节点指纹升级为倒计时，保留节点ID、布局和文字样式。不替换用户已改写的文案，不恢复用户已删除的节点。
- 购买仅触发 Demo 模拟提示，关闭可重新预览；不发起实际交易。所有旧模板与已有记录保持不变。

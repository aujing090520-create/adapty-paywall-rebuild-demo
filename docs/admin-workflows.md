# 后台配置操作语义

## 创建与关联挽留弹窗

1. 在画布找到要离开的页面，点击其“关闭页面”连接点；已有关系时点击关闭连线。
2. 已有弹窗：在“当前画布”选择它，点击“关联此内容”。这只增加关系，不复制弹窗。
3. 没有弹窗：点击“新建挽留弹窗”，生成可编辑的居中礼盒样式并直接关联。也可在“弹窗样式”选择空白。
4. 左侧“弹窗”加号是同一个创建入口；右侧页面的“设置关闭后显示”是同一份关系配置。
5. 顶部保存后，弹窗、组件和关闭关系一起保存在当前付费墙；模板默认内容不变。

| 对象 / 操作 | 实际结果 |
|---|---|
| 页面 | 流程中的一个 Screen，可设置初始页面或由按钮动作跳转 |
| 弹窗 | 画布中的一份可编辑内容，可以被多个页面共享 |
| 关闭后显示 | 前置页面的关闭事件 -> 目标弹窗或页面；不是目标自己的点击动作 |
| 当前画布 | 只列当前工作区真实可用页面、弹窗及兼容旧弹窗，不混入其他保存记录 |
| 已保存内容 | 历史复制来源，显示记录类别和短ID；“复制并关联”生成本画布独立内容 |
| 更换关联 | 改变当前来源页面目标；原内容仍在画布 |
| 解除关联 | 只解除当前来源，不删除内容，也不影响其他来源 |
| 删除弹窗 | 从本画布移除并清理所有来源与打开按钮引用；不物理删除共享历史记录 |
| 撤销移除 | 撤销刚才的解除或删除；发生后续内容修改后不会用旧快照覆盖新内容 |
| 隐藏 | 内容仍在文档，但不能触发；设置显示不可用提示 |
| 预览流程 | 从初始页面运行，编辑选择不随预览导航改变 |
| 预览弹窗 | 直接查看当前弹窗，不需要先手动触发 |
| 测试关闭触发 | 从当前弹窗关联来源页面启动，再点关闭验证实际关系 |
| 继续了解 / 返回 | 原位挽留弹窗默认返回来源；同一来源每次预览只拦截一次 |
| 暂时离开 / 关闭付费墙 | 结束当前预览；重新预览开始新会话 |

## 保存、复制与退出

- 名称、画布和关联属于同一工作区。保存写入当前浏览器，不代表真正发布付费墙到 SDK。
- 离开有未保存修改的工作区，可以“保存并继续”“放弃并继续”或“继续编辑”。保存失败或名称为空不会继续离开。
- 替换未保存画布前需确认；取消保持原内容。重复使用同一模板仍取模板默认值。
- 复制读取已保存完整画布与配置，打开未保存副本；副本修改不影响源文档，首次保存后才进入列表。
- 基础设置商品摘要与画布数据一致，进入“编辑画布商品”修改实际配置，不再生成临时假商品行。

## 边界

每个流程页面独立配置挽留是用户确认的 Demo 扩展能力。购买、恢复购买及统计仍按原 Demo 边界演示，不声称连接真实交易或外部分析服务。旧独立弹窗格式兼容保留，不批量迁移或清空用户保存记录。

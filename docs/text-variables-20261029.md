# 文字变量统一编辑

## 规则

- 普通文字、倒计时变量、商品变量、业务变量和列表条目变量共用富文本编辑器。一句正文可以包含多个变量，不再用倒计时字段下拉与普通文字二选一。
- 插入变量面板可按中文名称或变量键搜索，并按数据来源分组。倒计时变量只在所属倒计时内开放，条目变量只在数据列表内开放；不会凭空创建计时来源。
- 编辑框将变量显示为完整标签；画布显示解析结果。选区格式、插入位置、字重、删除、撤销、复制的占位符文本和保存重开均保持一致。未注册的变量保留原键并报告未知变量，不执行表达式。
- 旧timerField按同一变量定义表迁移为正文占位符，保留ID、位置、补零方式、样式和计时来源。迁移不改SKU记录、不自动保存用户记录。
- 保留此前确认的商品参数组件及其外部字段映射，不把参数退回可随意输入的商品文案。现有商品文字变量继续兼容。

## 扩展位置

- textVariableTokens.js定义计时变量键、中文名称及旧字段映射；同一表驱动可用选项、解析与迁移。
- textVariables.js集中定义其他变量与上下文列表。增加数据变量时注册名称、分组和取值；不再增加互斥的专用内容下拉。
- 数据仍以text/runs中的标准占位符保存，富文本变量标签只是编辑表现，不引入第二套业务数据。

## 倒计时结构修正

- 默认倒计时及已有的横向拆分计时内容统一为一个Text：同一正文包含标题、时分秒变量和分隔符，不再把数字底色作为拆分图层的理由。
- 原数字的底色、圆角、内边距和独立字号保存在富文本片段样式中，编辑和保存重开时保留；数字仍由所属Countdown解析。
- 时间来源、截止时间、补零变量、结束内容、兜底内容和商品数据不因合并改变。复杂自定义容器不强制拆解；迁移在打开编辑器时作用于文档副本，不自动保存用户记录。
- 721项测试通过；实际蓝色特权页已有记录验证：计时中仅1个文字图层、3个绿色数字片段、统一编辑后样式保留。

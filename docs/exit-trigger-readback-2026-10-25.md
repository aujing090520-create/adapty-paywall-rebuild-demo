# 退出触发可视化与新增Screen录屏核对

## 来源与边界

- 用户反馈：配置中看不出挽留弹窗由关闭前一页面触发。
- 新录屏20261025154034_rec_.mp4，46.35秒，原始3448×1984；只读抽帧检查。实际过程为创建付费墙、Settings、打开Add step、从Welcome Screen模板新建Screen，随后Screen并列、Continue连线和完整组件树出现。视频没有演示绑定退出优惠，不据此断言Add step会自动实现挽留。
- RevenueCat官方[多步骤与退出优惠文档](https://www.revenuecat.com/docs/tools/paywalls/creating-paywalls#configuring-exit-offers)：普通步骤由Button导航；退出优惠在付费墙设置绑定独立Offering，多步骤仅关闭最终Screen时触发。两者可以共享编辑能力，不能混用触发语义。
- 本次改动限已有退出绑定的可读性与同源呈现；不新增触发方式选择器，不把HT原弹层自动改为退出优惠，不改变原始素材、SKU及真实支付/关闭边界。

## 对照结果

| 环节 | 录屏中的Screen流程 | 挽留流程是否适用 |
| --- | --- | --- |
| 内容来源 | 空白 / 模板 / 已有付费墙 | 可以复用来源选择和真实组件复制；本轮未统一退出优惠的新建选择器 |
| 编辑表现 | 独立根节点、组件树、同画布编辑 | 已适用，仍保留独立优惠所有者 |
| 连接 | Continue导航到另一Screen | 不能直接照搬；退出优惠用关闭事件连接，不能作为普通下一步 |
| 入口 | Add step | 普通步骤仍使用该入口；退出优惠仍在付费墙设置绑定 |
| 触发 | 点击导航按钮 | 关闭最终可见、非辅助Screen；普通返回与关闭Sheet不触发 |
| 结束 | 由下一步动作决定 | 关闭优惠结束整个付费墙流程，不循环触发 |

明确后续差距：当前“新建退出优惠”直接创建默认空弹层，尚未复用录屏的空白/模板/已有付费墙创建流程；这是可复用的后续创建体验，不冒称本轮已实现。
